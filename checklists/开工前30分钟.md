# 开工前 30 分钟清单

新项目第一天，按顺序做完再写第一个页面。每项都能打勾才算完成。

## 0. 仓库（3 分钟）

- [ ] `node scripts/new-site.mjs ../08-新项目` 生成基座
- [ ] `npm install`，提交一次初始版本（含 `package-lock.json`）
- [ ] 确认 `.gitignore` 覆盖：`node_modules/`、`.next/`、`.next-validation/`、`.acl-*/`、`media/raw/*`、`.env*.local`
- [ ] 只保留一个包管理器（npm 或 pnpm），不要同时留两份 lock 文件

## 1. 事实（5 分钟）

- [ ] 填 `data/site.ts`：品牌名、主体全称、域名、电话、地址、服务区域、备案号
- [ ] 列出"必须客户确认才敢写"的清单：价格、工期、质保、资质、检测结论、案例授权
- [ ] 约定：没有确认的数字一律不写，页面用"以合同为准"这类可核实表述

## 2. 设计系统（7 分钟）

- [ ] 对照设计稿，把颜色填进 `tokens.css`（8 个角色）
- [ ] 字号 7 档、间距 8 档（4 的倍数）、圆角 3 档、层级 6 档
- [ ] 定字体方案：**自托管**（next/font/local）或系统字体栈；不引 Google Fonts 外链
- [ ] 断点只留 3 档：≤639 / 640–1023 / ≥1024，短屏例外单独一条

## 3. 页面与结构（5 分钟）

- [ ] 写清页面清单和 URL：单页 / 多页 / 是否需要详情页
- [ ] 每个页面有独立 title、description、H1 主题（不重复）
- [ ] 确认目录约定：`components/sections`（区块）、`components/ui`（通用件）、`data/`、`lib/`
- [ ] 语义结构先定：header / main / footer 平级，`main` 里只放正文
- [ ] 页面级机制只走三个入口：`useOverlayLayer` / `scrollToAnchor` / `<Reveal>`（见 README）

## 4. 素材（3 分钟）

- [ ] 图片原图放 `media/raw/`，跑 `npm run media` 生成 `public/media/`
- [ ] favicon / OG 图（1200×630）替换占位素材
- [ ] 视频预算：单个 ≤ 4 MB，且有 poster

## 5. 护栏（7 分钟）

- [ ] `npm run check` 全绿（lint + stylelint + typecheck + test + check:facts + check:assets + check:deps）
- [ ] 只有一个锁文件（npm 或 pnpm 二选一），`packageManager` 与之一致
- [ ] 同一能力只有一个库：动画、图标库、日期库各留一个（`npm run check:deps` 会拦）
- [ ] `npm run dev` 打开首页，确认 h1、正文、FAQ 在"查看源代码"里可见
- [ ] `npm run build` 通过
- [ ] 配置 CI（`.github/workflows/check.yml`），并设为合并前必须通过
- [ ] 约定提交流程：一次提交只做一件事，功能完成立刻提交

## 一句话验收

**30 分钟后，你应该能在不看代码的情况下回答：设计值在哪、事实在哪、页面级机制在哪、改坏了谁会拦我。**
