# 上线前验收清单

不要逐条"感觉没问题"，每条都要有可复现的验证动作。

## 内容与事实

- [ ] 所有数字、承诺、资质、案例都有来源；没有"待确认"内容上线
- [ ] 电话/地址/服务区域在页面、页脚、metadata、JSON-LD 完全一致（`npm run check:facts` 已过）
- [ ] 备案号是真实号码；没拿到就整行隐藏，不显示 XXXXX
- [ ] 案例图片、客户评价有授权；示例数据（虚构评价/占位价）确认没有进入正式构建

## 抓取与 SEO（GEO 第一层）

- [ ] 部署后 `curl -s <url> | grep -o "<h1[^>]*>[^<]*"` 能拿到 H1 文本
- [ ] 同一份 HTML 里能搜到正文段落、FAQ 答案、主要链接（不依赖 JS）
- [ ] `/robots.txt` 返回 200 且包含 Sitemap 地址
- [ ] `/sitemap.xml` 返回 200，URL 与实际域名一致
- [ ] title / description / canonical / og:title / og:description / og:image 都存在且不重复
- [ ] 分享链接（微信/微博/小红书）能出缩略图
- [ ] JSON-LD 语法有效，且与页面可见内容一致（电话、名称、地址、问答）

## 可访问性

- [ ] 键盘 Tab 一遍能走完：跳转链接 → 导航 → 正文 CTA → 页脚
- [ ] 焦点可见：浅色区焦点环对比度 ≥ 3:1（深色 `#141413` 或双色描边）
- [ ] 正文文字对比度 ≥ 4.5:1；大字（≥24px 常规 / ≥18.66px 粗体）≥ 3:1
- [ ] 图片 alt 描述真实内容；装饰图 alt=""
- [ ] heading 层级不跳级，每页只有一个 H1
- [ ] 弹窗：Esc 可关、焦点不出圈、关闭后焦点回到触发按钮、背景不可滚动
- [ ] `prefers-reduced-motion: reduce` 下无强制滚动动画

## 性能

- [ ] LCP < 2.5s、CLS < 0.1、TBT < 200ms（Lighthouse 移动端）
- [ ] 首屏关键资源 ≤ 300 KB；单图 ≤ 400 KB；视频 ≤ 4 MB；`public/` ≤ 60 MB
- [ ] 首屏大图/视频有 poster 或占位，不阻塞内容渲染
- [ ] 字体自托管，`font-display: swap`；没有阻塞渲染的第三方字体 CDN
- [ ] 图片走 `next/image`，没有被 ESLint 拦下的裸 `<img>`

## 响应式与交互

- [ ] 375 / 768 / 1440 三个宽度无横向滚动、无文字截断
- [ ] 所有按钮和链接可点击，锚点能跳到正确位置
- [ ] 表单（若有）只有服务端成功后提示成功；失败有重试或替代联系方式
- [ ] 咨询入口实测：电话可拨、地图可开、二维码可扫

## 工程与交付

- [ ] `npm run check` 全绿；`npm run build` 成功
- [ ] CI 通过，且分支保护已开启
- [ ] 没有 `.next-validation/`、`.acl-*/`、原始大图等无关文件进仓库
- [ ] 部署环境变量、域名、HTTPS 正常；刷新任意锚点可访问
- [ ] 打 tag 并保留本次上线记录（版本、日期、改动点）

## 一句话验收

**换一台没登录过的设备、断开开发环境，用真实 4G 网络打开链接，能看懂"你是谁、服务哪、怎么联系"——这就是通过。**
